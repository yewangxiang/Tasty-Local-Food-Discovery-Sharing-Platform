# CS183 Version Submission Note

This repository contains both Version 1 and Version 2 of the CS183 Project 17 codebase.

## Version 1

Version 1 is available through the `v1` release/tag.

The files uploaded around two months ago correspond to the first submitted version of the project, including the earlier frontend and backend code.

## Version 2

Version 2 is available through the `v2` branch and the `Version 2 Final Submission` release.

The V2 backend code is stored in the repository root, including:

- `src/`
- `pom.xml`

The V2 frontend code is provided as:

- `frontend2.zip`

Some older files inherited from the first version remain in the repository history and branch file tree. For the final Version 2 assessment, please refer to the `v2` branch, especially the updated backend code in the root directory and the uploaded V2 frontend package.

## Submission structure

- `v1` release/tag: Version 1 codebase
- `v2` branch: Version 2 final codebase
- `Version 2 Final Submission` release: final V2 release for submission
